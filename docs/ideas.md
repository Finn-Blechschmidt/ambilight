# Ideas (not planned, not implemented)

Extensions beyond the target architecture are collected here instead of being built unasked.

- Level shifter (74AHCT125 or 74HCT245) on the LED data line, if the 3.3 V logic level turns out to be the problem.
  This is a hardware fix that may become necessary rather than an optional extra.
- Check whether HDCP-protected sources (streaming) still produce a picture through the splitter and converter.
- Web UI or app for live configuration and calibration.
- Home Assistant integration (on/off, brightness, mode).
- Audio-reactive mode.
- Different effect modes (static colour, gradients) when no video signal is present.
